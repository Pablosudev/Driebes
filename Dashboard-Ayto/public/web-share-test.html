¿Se puede enviar la imagen a WhatsApp desde el navegador?

Esta página no forma parte del dashboard: es una prueba desechable para decidir si merece la pena implementar el envío del fichero. Ábrela en cada equipo que vaya a usar el dashboard y pásame el registro final.

1. Diagnóstico del navegador

Si «Compartir ficheros» sale en rojo, en este equipo no se puede adjuntar la imagen y no hay nada que hacer: seguiría usándose la URL.

2. Cargar la imagen

Se carga antes de compartir a propósito: si se descarga la imagen dentro del clic, Safari invalida el gesto y el compartir falla.
